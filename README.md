# Exemplo de Angular 19 com SSR
Esse projeto é uma demonstração do recurso do Angular para virar portfolio com o uso da ferramenta.

## Sobre o projeto 
O Exemplo será de uma loja de produtos com carrinho de compras e ambiente administrativo para gerenciar o estoque dos produtos, usando NgRX e SSR. Os dados serão lidos de json estático dentro do projeto. Será publicado no Github Pages
